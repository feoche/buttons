# MyButtons

MyButtons is a soundboard web app with a large catalog of buttons.

- Home: https://mybuttons.fr/
- API catalog: https://mybuttons.fr/.well-known/api-catalog
- API docs: https://mybuttons.fr/docs/api
- Skills index: https://mybuttons.fr/.well-known/agent-skills/index.json

## Notes for agents

Use `/.well-known/api-catalog` to discover machine-readable API links.
Use `/.well-known/agent-skills/index.json` to discover skill documents.
